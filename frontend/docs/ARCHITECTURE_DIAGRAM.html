6. Data Flow Sequence Diagram

sequenceDiagram
    participant U as User
    participant C as Component
    participant R as RTK Query
    participant A as API

    U->>C: Interact
    C->>R: useQuery()
    R->>R: Check Cache
    
    alt Cache Hit
        R-->>C: Return Cache
        C-->>U: Display Data
    else Cache Miss
        R->>A: Fetch Data
        A-->>R: Response
        R->>R: Update Cache
        R-->>C: Return Data
        C-->>U: Display Data
    end
    
    alt Mutation
        C->>R: useMutation()
        R->>A: POST/PUT/DELETE
        A-->>R: Confirm
        R->>R: Invalidate Cache
        R-->>C: Success
    end
